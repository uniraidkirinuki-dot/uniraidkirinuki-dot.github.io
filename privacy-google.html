EBI! Uploader プライバシーポリシー（Privacy Policy）

最終更新：2026年11月11日

「EBI! Uploader」（Google Cloud のアプリ「kirinuki-uploader」、以下「本ツール」）は、YouTubeチャンネル「EBI!」と「カニカツ」の運営者が、自分たちのチャンネルへ動画を送り、自分たちのチャンネルの数字を確かめるためだけに使う、運営者専用のツールです。ほかの人に向けたサービスではありません。

取り扱う情報

運営者が自分の Google アカウントでログインして許可した範囲で、YouTube Data API・YouTube Analytics API・Google Docs API を通じて次の情報を扱います。

  • 運営者自身のチャンネルの情報（チャンネル名、動画の一覧・タイトル・説明・公開状態）
  • 運営者自身の動画の数字（再生数・高評価数・視聴時間などの集計値）
  • 運営者が送る動画ファイル・説明文・サムネイル、運営者の動画へのコメントとその返信
  • 運営者が自分で作った Google ドキュメント（運営用のメモの書き込みだけ）
  • Google から発行されるアクセストークン

視聴者個人を特定するための情報は集めません。

使い道

  • 運営者のチャンネルへの動画のアップロード、説明文・再生リスト・公開時刻の管理、コメントへの返信
  • 運営者のチャンネルの数字の集計と、運営をよくするための分析
  • 広告・販売・第三者への提供には使いません。

保存と削除

  • トークンと集計した数字は運営者のPCの中だけに保存し、外部のサーバーには置きません。
  • 許可は Google アカウントの「サードパーティのアクセス」（https://myaccount.google.com/permissions）からいつでも取り消せます。取り消すと本ツールは使えなくなり、保存したトークンも削除します。

集計ツール（Google Cloud のアプリ「YouTube Analytics」）

YouTubeチャンネル「ゆにぬき」「EBI!」「カニカツ」の運営者が、自分たちのチャンネルの数字を集計して、週報・月報を作るためだけに使う運営者専用のツールです。

YouTube Data API・YouTube Analytics API で、運営者自身のチャンネルと動画の数字を読み取ります（動画の投稿や変更はしません）。

集計した数字とレポートは、運営者の Google ドライブ（スプレッドシート・スライド）に保存し、運営者の連絡用チャットに送ります。それ以外の第三者には渡しません。

Google API サービスのユーザーデータに関するポリシー

本ツールが Google API から受け取った情報の使い方は、限定的使用の要件を含む Google API Services User Data Policy に従います。本ツールは YouTube API サービスを使います。YouTube 利用規約と Google プライバシー ポリシーも合わせてご覧ください。

EBI! Uploader Privacy Policy (English)

Last updated: November 11, 2026

"EBI! Uploader" (Google Cloud app "kirinuki-uploader", the "Tool") is a private tool used only by the operator of the YouTube channels "EBI!" and "カニカツ" to upload videos to, and read statistics of, the operator's own channels. It is not offered to anyone else.

  • Information we handle: through the YouTube Data API, YouTube Analytics API and Google Docs API, within the permissions the operator grants with their own Google account: the operator's own channel and video information, aggregated statistics of the operator's own videos, the videos, descriptions, thumbnails and comment replies the operator posts, Google Docs created by the operator (for writing internal notes only), and the access tokens issued by Google. We do not collect information to identify individual viewers.
  • How we use it: only to upload and manage videos on the operator's own channels, reply to comments, and analyze the operator's own channel statistics. We do not use it for advertising, sale, or sharing with third parties.
  • Storage and deletion: tokens and statistics are stored only on the operator's local computer, not on any external server. Access can be revoked at any time at https://myaccount.google.com/permissions; we then delete the stored tokens.
  • Report tool (Google Cloud app "YouTube Analytics"): a private tool used only by the operator of the YouTube channels "ゆにぬき", "EBI!" and "カニカツ" to aggregate the statistics of the operator's own channels and produce weekly and monthly reports. It reads statistics of the operator's own channels and videos through the YouTube Data API and YouTube Analytics API (it does not upload or change videos). The aggregated statistics and reports are stored in the operator's Google Drive (Sheets and Slides) and sent to the operator's own team chat; they are not shared with any other third party.
  • Google API Services User Data Policy: the Tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The Tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
